## 🎨 ตัวอย่างการใช้ฟอนต์ (สำหรับเว็บ/ดีไซน์)

ถ้าจะเอาไปทำการ์ดหรือหน้าเว็บ สามารถโหลดฟอนต์จาก Google Fonts แล้วใส่ตาม CSS แบบนี้ได้:

```html
<link href="https://fonts.googleapis.com/css2?family=Sarabun&family=Dancing+Script&family=Noto+Sans+JP&display=swap" rel="stylesheet">
```

```css
.thai   { font-family: 'Sarabun', sans-serif; }
.italian{ font-family: 'Dancing Script', cursive; }
.japanese{ font-family: 'Noto Sans JP', sans-serif; }
```
